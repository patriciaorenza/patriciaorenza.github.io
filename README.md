# patriciaorenza.github.io

Source for my professional portfolio: **https://patriciaorenza.github.io/**

It's a plain static site (HTML, CSS and a little JavaScript). There's no build step and nothing to install.

## Files

| Path | What it is |
|---|---|
| `index.html` | All page content: about, projects, experience, coaching, contact |
| `style.css` | Layout, colours and typography |
| `script.js` | Rotating tagline and the mobile menu |
| `assets/Patricia_Orenza_Resume.pdf` | The resume behind the "Download Resume" button |
| `assets/airbnb/` | Charts shown on the Airbnb project card |

## How it's published

GitHub Pages serves the `main` branch as it is. Any change merged into `main` goes live, usually within a minute or two.

## Updating

- **Resume:** upload the new PDF with exactly the same name, `Patricia_Orenza_Resume.pdf`, into `assets/`. That replaces the old one, and the download button keeps working.
- **Project images:** put them in `assets/<project-name>/` and use lowercase, hyphenated file names.
- **After any change:** open the live site and check the part you changed.
